## 🎯 What Is SpaceportVbase?

SpaceportVbase is a **GeoAI agent** that identifies and ranks the best locations for spaceport development across Malaysia.

It combines **live geospatial data**, **real-time weather**, **geographic scoring rules**, and a **memory system** — all behind **one button**.

> **One click. Instant result. No explanation needed.**
